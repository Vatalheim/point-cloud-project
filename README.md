# Веб-приложение для визуализации и редактирования облаков точек (Cesium)

MVP кроссплатформенного веб-сервиса для потоковой загрузки, валидации, фоновой конвертации массивов лазерного сканирования (LAS/LAZ) в иерархический тайловый формат Cesium 3D Tiles с поддержкой интерактивного редактирования точек и управления слоями.

## 🚀 Архитектура и стек технологий

Проект построен на базе контейнеризированной микросервисной архитектуры:

* **Frontend:**
  * React 18, Vite 5, `vite-plugin-cesium`;
  * **3D-движок:** CesiumJS 1.115+ (World Terrain, OSM 3D Buildings);
  * **Геоподложка:** Esri World Imagery (открытый спутниковый провайдер без платных ключей);
  * **Рендеринг и стилизация:** Шейдерный движок `Cesium3DTileStyle` (динамическая фильтрация точек по евклидовой дистанции `${POSITION_ABSOLUTE}`).

* **Backend & Processing:**
  * Python 3.11, FastAPI, Uvicorn;
  * **Валидация метаданных и СК:** `laspy[lazrs]` (чтение проекций EPSG/CRS и счетчиков точек);
  * **Конвертер:** `py3dtiles` (перепроецирование координат в ECEF EPSG:4978 и нарезка в пирамиду `tileset.json` + `.pnts`);
  * **Асинхронный воркер:** `FastAPI BackgroundTasks` с защитой от переполнения буфера вывода.

* **Reverse Proxy & Инфраструктура:**
  * Nginx (маршрутизация API `/api/` и стриминг статических тайлов `/tilesets/`);
  * Docker Compose (изолированная среда со связанными volumes);
  * GitHub Actions (CI-пайплайн: модульное тестирование `pytest` + проверка сборки SPA).

## 📦 Быстрый запуск

### 1. Требования к окружению
* Установленный **Docker Desktop** (с поддержкой WSL2 на Windows или Docker Engine на Linux);
* Утилита **Git**.

### 2. Запуск локального стенда
Склонируйте репозиторий и запустите сборку контейнеров:

```bash
git clone https://github.com/Vatalheim/point-cloud-project.git
cd point-cloud-project
docker compose up -d --build
